# 🦝 Gonzo Tech

> Хардкорный техно-индустриальный мод про энергетику для **Minecraft 1.21.4 (NeoForge)**.
> Прогрессия как физический язык: пар → тепловая энергетика → деление → кремний → синтез →
> токамаки → ИИ → космос → сферы Дайсона → антиматерия → чёрные дыры → червоточины.

## 🌍 О чём это

Gonzo Tech — это долгая индустриальная прогрессия, построенная вокруг одной идеи:
**исследование как играбельная головоломка**, а не как гринд рецептов.

Ключевое отличие от других тех-модов — **физика мира детерминирована и одинакова на всех сидах**.
Точки плавления, теплопроводность, поведение реакторов и турбин — это постоянный физический
язык, который игрок учит один раз и переносит из мира в мир (вдохновение — Thaumcraft).

Сид меняет **не законы физики, а замок исследования**: структуру уравнения, которое нужно собрать.
Одна и та же технология открывается всегда одинаково — «элегантная» формула из 3 узлов и
«франкенштейн» из 30 узлов просто разблокируют один и тот же тир. Единственная цель головоломки —
довести баланс уравнения до **≥ 90 %**.

### 🧮 Движок формул — `chalkboard.core`

Порт исходного TypeScript-движка на Java. Проверить без Minecraft:
`./gradlew compileJava && java -cp build/classes/java/main com.gonzotech.chalkboard.core.SelfTest`

| Класс | Роль |
|---|---|
| `DimVec` | 7-мерный вектор размерности СИ `[L, M, T, I, Θ, N, J]` |
| `Quantity` / `Quantities` | Физические узлы («мелки»): символ, вектор, категория, тир |
| `Expr` | Неизменяемое дерево выражения (Slot / Num / Op / Pow / Eq) |
| `Evaluator` | Модель баланса: слой размерности × числовой слой − штрафы |
| `Analysis` | Результат оценки: `sD`, `sN`, `sFinal`, конфликты, «любовь» узлов |
| `Manipulate` | Структурные правки дерева (drag&drop: центр/лево/право/верх/низ) |
| `GameSolver` | Сид-детерминированная генерация 16 головоломок (Greedy Vector Reduction) |
| `DiscoveryDef` | Статические определения 16 открытий (тиры, узлы, темы) |
| `ChalkboardWorldData` | `SavedData`: пре-генерация всех головоломок на старте мира |
| `Serde` | JSON-сериализация деревьев выражений |
| `SelfTest` | Headless-проверка паритета с оригинальным движком |

## ⚙️ Фаза 2 — паровая ветка энергетики

Первая ветка производства энергии. Это **не** классический мультиблок: каждый блок
просто хочет видеть нужного соседа вплотную и передаёт ему ресурс напрямую (провода —
позже). Разорви цепочку — и звенья перестают работать.

```
[Топка] --GTH--> [Паровой котёл] --Steam--> [Ген. Стирлинга] --GTU--> [Электропечь]
  уголь              + вода                       (пар)                  (переплавка)
```

| Блок | Что делает |
|---|---|
| 🔥 **Топка** | Жжёт топливо → `GTH`; может попутно плавить руду/еду как печь (побочка). Отдаёт GTH котлу. |
| ♨️ **Паровой котёл** | `GTH` + вода → `Steam`. Требует топку рядом. *(потом станет сложным 3D-объектом)* |
| ⚙️ **Генератор Стирлинга** | `Steam` → `GTU` («электричество»). Требует котёл рядом. |
| ⚡ **Электрическая печь** | Плавит на `GTU`, без слота топлива. Требует Стирлинг рядом. |

**Ресурсы** (ёмкости и баланс — в одном месте, `energy/MachineDefs.java`):
`GTH` (GonzoTechHeat, тепло) · `Steam` (пар, mB) · `GTU` (GonzoTechUnits, энергия) ·
`Water` (вода, mB; 1 ведро = 1000 mB). Логика хранения — переиспользуемый `ResourceBuffer`.

Все четыре блока: свой BlockEntity + меню по ПКМ + шкалы в GUI, лежат в креатив-вкладке
**Gonzo Tech Functional**. Текстуры — простые заглушки (перерисовать/смоделировать в Blockbench).

## ⛏️ Материальная база

**26 руд** (`OreDefinition.ALL` — единственный источник правды): calcium, aluminum, magnesium,
sulfur, manganese, titanium, barium, zinc, tin, boron, chromium, nickel, cobalt, silver, iodine,
tungsten, mercury, uranium, zirconium, thorium, platinum, tellurium, palladium, cesium, iridium,
osmium.

Каждая руда генерируется в **host-вариантах** (`STONE` / `DEEPSLATE` / `NETHER` / `CALCITE`) —
каждый вариант это отдельный зарегистрированный блок со своей твёрдостью, тиром кирки, лутом и XP.

**Особые руды:**
- **Цезий** — «закрытая» руда безопасна, но при контакте грани с воздухом/водой каждое
  взаимодействие вызывает мини-взрыв (урон/отбрасывание, но без разрушения блоков).
- **Йод** — сыплет фиолетовые частицы «как редстоун» при ЛКМ/ПКМ, даёт XP.

**~45 слитков и сплавов** (`ModItems.INGOT_IDS`): от чистых металлов до steel, stainless_steel,
nitinol, invar, neodymium, semiconductor, stellite, alnico, cantor, vitreloy и др.

## 🛠️ Стек и запуск

- **Minecraft** `1.21.4` · **NeoForge** `21.4.157` · **Java** `21`
- **NeoForge ModDev** `2.0.144` · **Parchment** mappings `2025.02.16`

```bash
./gradlew runClient    # запуск клиента с модом
./gradlew runServer    # выделенный сервер
./gradlew runData      # генерация датапак-ресурсов
```
