# Работа с кодом агента и текстурами автора

Этот документ фиксирует наш рабочий цикл для ветки **`arena/01a08d55-gonzotech`**:

> **Агент** делает код, регистрации, JSON и временные texture placeholders →
> **автор** скачивает актуальный `source-code.zip` этой ветки, рисует/заменяет PNG
> на своём компьютере и коммитит только текстуры обратно в эту же ветку →
> **агент** продолжает работу уже поверх кода и новых текстур.

Так в одной последовательной истории всегда оказываются последний патч кода и
соответствующие ему финальные ассеты.

---

## 1. Главное правило

- Рабочая ветка этого цикла: **`arena/01a08d55-gonzotech`**.
- Не работаем через `main` и не создаём параллельную ветку для текстур.
- Настоящий путь к текстурам в этом проекте:

  ```text
  src/main/resources/assets/gonzotech/textures/
  ```

  Важно: папки `src/main/resources/gonzotech/textures/` **не существует** —
  обязательная часть пути здесь `assets/`.
- Агент создаёт только временные технические PNG, если они требуются новому
  контенту. Финальный pixel-art заменяет автор.

---

## 2. Цикл «код агента → рисунок автора → продолжение работы»

### Шаг A — агент закончил патч

После завершения задачи агент коммитит и пушит код в рабочую ветку. Перед тем
как брать исходники для рисования, убедись, что в GitHub выбрана именно ветка
`arena/01a08d55-gonzotech`, а не `main`.

### Шаг B — скачать снимок с кодом

1. В GitHub открой репозиторий и переключатель веток.
2. Выбери `arena/01a08d55-gonzotech`.
3. Скачай **Code → Download ZIP** (`source-code.zip`).
4. Распакуй архив и рисуй, опираясь именно на этот снимок: в нём уже лежат
   последние регистрации, модели, blockstates и placeholder-файлы агента.

ZIP — это удобный снимок исходников, но в нём нет каталога `.git`. Поэтому
сам архив нельзя использовать для `git commit` / `git push`: готовые PNG нужно
перенести в локальный Git-клон репозитория либо загрузить через веб-интерфейс
GitHub.

### Шаг C — нарисовать и заменить PNG

Рабочая папка художника:

```text
src/main/resources/assets/gonzotech/textures/
```

Обычно меняются подпапки:

```text
block/        — текстуры блоков и труб
item/         — предметы
entity/       — сущности, если появятся
gui/          — интерфейсы и страницы заметок
environment/  — небо, солнца, планеты, ЧД
particle/     — частицы
```

Правила:

1. **Сохраняй точные имя, регистр и расширение** placeholder-файла, если это
   замена уже зарегистрированного ассета.
2. Для нового изображения используй только lowercase-пути:
   `a-z`, `0-9`, `_`, `-`, `.`, `/`.
3. Не удаляй модели, blockstates, рецепты или Java-файлы из ZIP ради замены
   ассета — меняются именно PNG в каталоге `textures`.
4. Если новый PNG требует нового id или иной UV-раскладки, не угадывай: сообщи
   агенту. Он синхронно поправит модель/рендер и создаст нужный placeholder.
5. Специальные требования к трубам, их UV и временным ассетам фиксируются в
   `LOGISTICS-TEMP-NOTES.md`.

## 3. Вернуть готовые текстуры в ветку через Git

Сначала нужен обычный клон репозитория (один раз). Вместо `<repo-url>` используй
URL репозитория Gonzo Tech из GitHub:

```bash
git clone <repo-url> gonzotech
git -C gonzotech fetch origin --prune
git -C gonzotech switch --track origin/arena/01a08d55-gonzotech
cd gonzotech
```

Если клон уже есть, перед переносом PNG обнови его без потери своей работы:

```bash
git status
# Если status чистый:
git fetch origin --prune
git switch arena/01a08d55-gonzotech
git pull --ff-only origin arena/01a08d55-gonzotech
```

Теперь перенеси нарисованные файлы из распакованного ZIP в этот клон, сохраняя
путь `src/main/resources/assets/gonzotech/textures/`, и проверь будущий коммит:

```bash
git status --short
git add src/main/resources/assets/gonzotech/textures
git diff --cached --stat
git diff --cached --name-status
git commit -m "Текстуры: <краткое описание ассетов>"
git push origin arena/01a08d55-gonzotech
```

Примеры сообщений:

```text
Текстуры: паровые машины первой эры
Текстуры: фильтр и предметная логистика
Текстуры: окружение Европы и частицы ЧД
```

После успешного push просто сообщи агенту, что новые PNG уже в ветке. Следующую
задачу он начнёт с этой версии.

## 4. Если агент запушил код, пока рисовались текстуры

Это нормальная часть нашего цикла. Не делай `reset --hard`: он может удалить
нарисованные, но ещё не закоммиченные PNG.

1. Сначала сохрани незакоммиченные текстуры в отдельную папку вне клона или
   сделай локальный коммит только с ними.
2. Обнови ветку:

   ```bash
   git pull --rebase origin arena/01a08d55-gonzotech
   ```

3. Если Git сообщает о конфликте в PNG, автоматического осмысленного слияния
   изображений не существует. Выбери нужный файл целиком, затем:

   ```bash
   git add src/main/resources/assets/gonzotech/textures
   git rebase --continue
   git push origin arena/01a08d55-gonzotech
   ```

4. Если новый код агента поменял имена или расположение ассетов, возьми их из
   свежей версии в качестве шаблона и перенеси свою отрисовку в новые файлы.
   При сомнении остановись и спроси агента до push.

## 5. Альтернатива: один PNG через GitHub Web

Для небольшой правки можно открыть в GitHub нужный файл в ветке
`arena/01a08d55-gonzotech`, нажать **Add file → Upload files**, загрузить PNG в
тот же путь и внизу выбрать:

```text
Commit directly to the arena/01a08d55-gonzotech branch
```

Перед подтверждением ещё раз проверь путь: он должен начинаться с
`src/main/resources/assets/gonzotech/textures/`.

---

## 6. Короткая памятка

| Что делаем | Где / как |
|---|---|
| Агент добавил новый объект | Скачиваем ZIP именно с `arena/01a08d55-gonzotech` |
| Рисуем ассеты | `src/main/resources/assets/gonzotech/textures/` |
| Проверяем список PNG | `git status --short` |
| Добавляем только ассеты | `git add src/main/resources/assets/gonzotech/textures` |
| Смотрим, что войдёт в коммит | `git diff --cached --stat` |
| Возвращаем рисунки | `git push origin arena/01a08d55-gonzotech` |
| Избегаем при незакоммиченных рисунках | `git reset --hard`, случайного checkout другой ветки |

> Когда Arena создаст другую рабочую ветку для новой сессии, сначала нужно
> договориться о новом имени и обновить этот документ. В рамках текущей сессии
> единственной веткой остаётся `arena/01a08d55-gonzotech`.
