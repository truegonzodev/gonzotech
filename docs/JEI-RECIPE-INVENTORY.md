# JEI-рецепты для проверки в игре

Срез по текущему источнику (`0.3.220`). Счётчик — число отображаемых JEI-записей, а не количество вариантов предмета внутри слота. Альтернативы в одном слоте считаются одной записью. Это список для визуальной проверки; он не меняет машинную механику.

## Машинные категории

| Категория | Записей | Группы для проверки |
|---|---:|---|
| Электропечь I | `N` | Все рецепты типа `SMELTING`, загруженные в игре; число зависит от Minecraft, модов и датапаков. |
| Электропечь II | `N` | Тот же набор `SMELTING`, отдельная раскладка и параметры тира II. Ванильная категория плавки остаётся без изменений. |
| Дробилка | **79** | 26 типов руд GonzoTech → 46 отдельных host-вариантов рудных блоков; 20 ванильных рудных блоков; 13 пород/простых материалов. |
| Центрифуга | **35** | 22 обычные руды GonzoTech (raw и host-варианты собраны как альтернативы одного входа); 4 специальные руды-блока — сера, марганец, йод, ртуть; 9 ванильных рудных семейств. |
| ПЦФСОЗ | **1** | Жёлтый кек → уран-238; уран-235 указан как шансующий побочный выход. |
| Измельчитель | **56** | 43 слитка GonzoTech с пылью → пыль; 2 ванильных слитка → пыль; raw-марганец → пыль и кварц → песок; 8 древесных входов → смолистые опилки; один общий рецепт шерсти → 3 нити. |
| Пресс | **21** | 11 пластин; 4 провода; 2 ядра; 3 raw-руды → слитки; 1 сборка ТВЭЛ. Формы и пуансон показаны как оснастка, не отдельные рецепты. |
| Сплавочная печь | **14** | Именованные формулы: чугун, сталь, нержавеющая и кортеновская стали, нитинол, инвар, ферромагнитный сплав, Кантор, ВР20, стеллит, альнико, теллурид, витриллой и полупроводниковый сплав. Динамический `custom_alloy` не является фиксированным рецептом и отдельной записью не показывается. |
| Химический завод | **12** | Графит — 1 рецепт; синтезы EDTA, цианата натрия, полиэтилена, ПВХ, двух смол, целлулоида, резины, цистеамина, пентацина и ДТПА — 11. |

| Кремниевая фабрика | **3** | Суп + заготовка чипа → варианты чипа 1, 2 и 3; GTU показывается за полный цикл литографии. |
| Ферментационный чан | **6** | Один общий рецепт растительной органики; 5 отдельных входов: протобрага, фруктовая брага, золотое яблоко, золотая морковь, зачарованное золотое яблоко. |

| Дистиллятор | **4** | Брага и сусло — каждый тип показан отдельно для чистого дистиллята и загрязнённого выхода. |
| Ректификатор | **1** | Дистиллят → ректификат. |
| Разливной кран | **3** | Бутылка водки; кружка пива; ведро пива. Входы жидкости: 128/128/1000 mB соответственно. |

**Сумма фиксированных записей:** 279, без двух электропечей. Если в загруженном наборе ровно `N` рецептов `SMELTING`, вместе с электропечами будет `279 + 2N` записей. Точное `N` определяется игровым `RecipeManager` и не зафиксировано в Java-таблицах проекта.

## Текстовая категория

| Категория | Записей | Содержимое |
|---|---:|---|
| Багровый обсидиан | **1** | Только заданный текст о соприкосновении лавы и блока красного камня; видимых слотов нет. |

Итого фиксированных записей, включая текстовую: **280**, плюс `2N` записей электропечей.

## Примечания к счёту

- У дробилки 46 записей для рудных блоков GonzoTech, потому что один тип руды может иметь несколько host-блоков. Это 26 типов руды, а не 46 разных металлов.
- У шерсти, центрифужных вариантов raw/host и входных форм сплавов несколько предметных альтернатив внутри JEI-рецепта; они не умножают число записей.
- Категории открытия/ванильного крафта не включены в этот машинный перечень. JEI-рецепты не скрываются.
