# AUDIT-2026-09-26 — диагностика гейтов в подсказке

**Дата:** 26.09.2026 · **База:** `b57a4c8` · **Версия:** `0.3.19`
**Статус:** реализовано; игровая приёмка открыта. Без изменения механик/баланса.

## 1. Контракт и исправление

- Только **креатив ∧ F3+H ∧ клиентский переключатель ВКЛ**. Поиск без игрока безопасно пропускается.
- В конце `UniversalTooltip`, **после** существующих ванильных ID/компонентов: `крафт-гейт открытие 1`, `рецепт-гейт открытие 1`, оба `DARK_GRAY` (&8). Ванильные строки не дублируются; обычная информация предмета сохранена.
- Опция **«Расширенные расширенные подсказки»**, стандартный экран NeoForge, default **true**; `config/gonzotech-client.toml` → `extendedAdvancedTooltips`. Не требует перезапуска мира и не ослабляет гейты.
- Физический гейт: существующие `Phase3Events.requiredTierFor` + общий предикат дополнительного солнечного условия. Книга: те же списки выдачи из `RecipeUnlocks`, `TierTwoCrafting`, `TierThreeCrafting` через read-only методы; не префикс предмета.
- Сервер сопоставляет **результаты реально загруженных рецептов** с правилами. Minecraft 1.21.4 не даёт клиенту все скрытые серверные рецепты: компактный индекс отправляется при входе и `/reload`, не вычисляется при каждом наведении. Выход из мира очищает клиентский индекс; до синхронизации — «ожидание данных сервера».
- Разные рецепты одного предмета объединяются без повторов: альтернативы через `/`, совместные условия через `+`. Солнечные часы — открытие 2 + уже встреченный багровый день; временные рецепты — 20 минут личного наигранного времени.
- `нет` означает отсутствие **гейта Gonzo Tech**, а не гарантированное наличие рецепта, уже полученное игроком открытие или выполнение ванильных критериев книги. Незагейченный альтернативный рецепт сохраняется рядом с загейченным.

## 3. Минимальная игровая приёмка

1. Креатив, F3+H, переключатель ВКЛ: у `first_pump` внизу **1/1**; у `wrench` **нет/1**, у `sheathing` **нет/3**. ID/компоненты ровно один раз, диагностика тёмно-серая.
2. Переключить F3+H, конфиг, survival/adventure/spectator: два новых пункта отсутствуют, старая подсказка не меняется. Поиск в креативе не падает.
3. Конфиг ВЫКЛ → перезапуск клиента → ВЫКЛ сохранён; включить через экран без перезапуска мира.
4. Проверить `electric_motor`, `energy_module`, солнечные часы; у ванильного древесного угля альтернативы **нет / 20 минут игры** при обычном наборе рецептов.
5. Dedicated server, два клиента с разными настройками; вход, `/reload`, смена мира/сервера. Датапаком удалить/переназначить выход одного из загейченных рецептов: индекс должен отражать новый набор без устаревших предметов. На сервере нет загрузки GUI-классов.
