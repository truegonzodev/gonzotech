# Сухие коэффициенты активной зоны — 0.3.238

**Дата:** 18.10.2026 · **База модели:** `docs/MatrixCoefficients.zip` · **Область:** диагностические H/L по Shift+ПКМ; это не runtime-симуляция.

## Авторское правило 0.3.238

`H` и `L` — сухие структурные показатели: они описывают только конфигурацию внутренних блоков и **не зависят от количества загруженных ТВЭЛов**. Загрузка топлива выводится отдельно и не передаётся в расчёт коэффициентов. Поэтому пустое меню топлива не обнуляет H/L.

Для контрольной полностью заполненной ячейками `FUEL` сетки 3×3×3 (27 чехлов) при настройках архивной модели ожидаются:

- **H = 2.6971** — безразмерный максимальный локальный тепловой индекс;
- **L = 0.8812** — безразмерная пиковая утечка, то есть **88.12%** шкалы.

Это игровая калибровочная модель, не физическая температура, мощность, критичность или прогноз реального реактора.

## Сборка расчётной сетки

При Shift+ПКМ валидатор проверяет сохранённые bounds сформированного куба. `ReactorMatrix` исключает наружную оболочку и читает каждый фактический блок внутренней зоны. Клетки отображаются так:

| Фактический блок | Материал модели |
|---|---|
| `third_uranium_reactor_fuel_sheath` | `FUEL` — фиксированный единичный опорный источник на чехол |
| `graphite_block` | `GRAPHITE` |
| `boron_block` | `BORON` |
| `barium_block` | `BARIUM` |
| `minecraft:water` | `WATER` |

Каждая клетка `FUEL` получает фиксированную исходную интенсивность модели, установленную в архивном `Rules`. `ReactorMatrix.evaluate` не читает инвентарь и не задаёт `fuelStrength` из загруженного числа ТВЭЛов. Реальные блоки/позиции и их материалы по-прежнему влияют на коэффициенты.

## Значение вывода

- `H` — максимум локальной тепловой нагрузки после графового теплопереноса, нормированный на зафиксированный бюджет модели; значение может быть выше 1.
- `L` — максимальная утечка через одну грань, нормированная в `[0,1)`; сообщение панели показывает также процент.
- Количество ТВЭЛов в чехлах и среднее `T/S` отображаются как отдельные данные о загрузке и не меняют H/L.
- Вода, графит, бор и барий используют только коэффициенты из архива; отсутствующие параметры не назначаются.
- Свинцовые поршни, sticky-поршни и головки исключены из внутреннего whitelist; неизвестные/запрещённые блоки не доходят до расчёта.

Сохраняются все оговорки архива: 26 направлений, быстрый/тепловой сигнал, итерационное рассеяние и графовый теплоперенос. Значения безразмерные, зафиксированы для игры и не являются ядерными константами. Выгорание, температура, теплоотвод, GTH и аварийная динамика не реализованы.

## Проверки и границы

- `audit/reactor_matrix_integration_test.py` проверяет, что H/L строятся по живым блокам сохранённой зоны, не зависят от `loadedTvelCount`, и не возвращает mapping для свинцовых поршней.
- `audit/MatrixCoefficientsTest.java` закрепляет контрольные значения для 27 чехлов.
- `audit/reactor_matrix_test.py` выполняет Java-оракулы при наличии JDK; в текущей среде Java/Javac отсутствуют, поэтому реальная Java-компиляция и запуск не подтверждены.
- Матрица запускается только по Shift+ПКМ. Автоматический реакторный тик, burnup, физическая температура и генерация GTH не входят в этот патч.
