# Чистая комната и качество воздуха

Срез кода: **0.3.311**, `c15083f`; документальная база: `42730c3`. Сверка/миграция: 27.10.2026.


## Модель

`CleanRoomDetector`, `RoomTopology`, `RoomLedger`, `CleanRoomSystem` разделяют геометрию, сохранённое/развивающееся состояние воздуха и серверный шаг. Чистая комната — замкнутый пригодный контур с очисткой, не просто наличие блока-фильтра рядом с игроком. Гермодвери/тамбур участвуют в топологии; обычная железная дверь не автоматически пригодный cleanroom-материал.

Грязность игрока/экипировки, объём воздуха, очиститель и фильтр — разные вклады. Пылемер показывает соответствующее состояние; радиационный дозиметр не заменяет его. Открытый воздух и неполный/недоступный контур не следует объявлять чистыми по отсутствию загруженных данных.

## Производство

`SiliconFactoryBlockEntity` читает чистоту и получает брак на стадиях конвейера. Грязь означает больший брак, а не утверждённое правило «машина вообще не включается». Фабрика/три чипа уже реализованы, это не будущий семиступенчатый wafer pipeline из старого концепта.

Фильтр/очиститель и расходники имеют текущие таблицы кода; не вводить «общий фильтр для любой химии» из раннего предложения. Разгрузка/изменение клетки и кэш геометрии не должны вызывать полный обход каждый тик; топология пересчитывается по реальным событиям/валидности.
