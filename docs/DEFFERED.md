# Отложенные открытые задачи

Срез: 0.3.311, миграция 27.10.2026. Не текущая работа. Миграция DOC-001 закрыта; статус удерживается в [CURRENT-STATE](CURRENT-STATE.md). Новые цены/механики требуют согласования автора; перенос записи не является разрешением реализации.

Источник Р/Е/З/П-нумерации: [Пятилетка II](archive/legacy-0.3.311/PIATILETOKA-2026-10-26.md). Старые 69/54/15 — исторические счётчики, не число сегодняшних задач.

<a id="d-r1"></a>
### D-R1 — Смета автошахтного комплекса

**Статус: отложено.** Ждёт автора: цены/рецепты Плотника, геофона, источника колебаний, бура, рабочего блока, карты памяти. Креативная группа уже перенесена; это не получение в survival. См. AUTOMINER и PROGRESSION.

<a id="d-r2"></a>
### D-R2 — Смета реактора I

**Статус: отложено.** Ждёт автора: рецепты обшивки, панели, чехла и клапана. Runtime/выгорание/аварии уже есть; не ставить задачу «написать реактор заново».

<a id="d-r3"></a>
### D-R3 — Получение солнечной панели

**Статус: отложено.** Нужен согласованный рецепт/путь получения. Панель относится к открытию 4, не смешивать с текущим пакетом III.

<a id="d-r4"></a>
### D-R4 — Получение телифона

**Статус: отложено.** Утвердить рецепт прибора либо его креативный статус. Отдельная старая идея моба-телифона не заменяет этот вопрос.

<a id="d-r5"></a>
### D-R5 — Получение пучков и скваженных труб

**Статус: отложено.** Уточнить намерение: пучки собираются ключом в мире; bore_pipe участвует в бурении. Отсутствие JSON само по себе не доказывает недостижимость. Подтвердить действующий маршрут и описать его.

<a id="d-r6"></a>
### D-R6 — СНУП — граница будущего цикла

**Статус: отложено.** Ждёт решения автора о производстве/потреблении и эпохе. Не добавлять СНУП в ядерную топку или первый урановый чехол как побочный фикс.

<a id="d-r7"></a>
### D-R7 — Производство дополнительных изотопов

**Статус: отложено.** U-233, Pu-238/242, оружейный Pu, Th-229: решить объём наработки/трансмутации. Наличие предметов и downstream-рецептов не равно доступному производству.

<a id="d-r8"></a>
