## 0. Правила контента (стоящие, автор 01.10.2026)

  смежных по смыслу ресурсов** (графит к углю/рудам, изотопы к изотопам).

## 2. Реактор №1: классический твердотопливный, урановый цикл, тепловые нейтроны

### 2.1 Компоненты (авторский список; «●» — мои дополнения, §5)

1. **Наполнитель** (`third_filler`, есть) — добавить функционал: набивка
   капсул-твэлов урановым топливом. База: `EPOCH3-BASE §2.3` (универсальный
   бак, таблица несовместимостей, ампулы).
2. **Щипцы/котелок** — записи подняты: щипцы + ковш полностью спроектированы
   (`EPOCH3-BASE §2.8`: предмет-контейнер до 64 шт, −90 % токсичность /
   −70 % радиоактивность излучаемого, станок забирает содержимое, щипцы дропом;
   открытый вопрос §2.8: −60 % в тултипе или «19 из 64»), **в коде их ещё нет**.
   «Котелок» в записях не находится — см. дыру Д-2.
3. **Центрифуга ОЦФИД** — обогащение урана в уже существующие изотопы.
   В старых записях — ПЦФОЗ (`EPOCH3-BASE §2.4`): изотопы U-235/238/233,
   плутоний, Th-229 зарегистрированы и фонят, но не имеют НИ ОДНОГО рецепта —
   центрифуга единственная дверь в изотопы. Там же: жёлтый кек → фторид →
   каскад разделения (абразив + фильтры + вода + GTU), ответ автора «отдельный
   станок». ⚠ Д-1: ОЦФИД и ПЦФОЗ — одно и то же (переименование)?
4. **Усиленная паровая труба + усиленный паровой узел** — транспорт пара под
   давлением (см. §3). ⚠ Д-5: новый тир-III или давления-рейтинг существующих?
5. **ВД пар** — развилка «отдельная жидкость vs параметр давления», разбор §3.
6. **Панель ядерного реактора** — функциональный блок; предположительно GUI
   мультиблока (512×512 −128; шкалы: реактивность/температура/давление/GTH).
7. **Обшивка реактора** — структурный блок оболочки (formed-текстура, CTM).
8. **Чехол** — ⚠ Д-3: роль? Биозащита поверх обшивки / отдельный слой / часть
   зоны?
9. **Борный стопор нейтронов** — управляющий стержень; бор в моде есть
   (борная руда, бура, слиток, блок). Задвигается поршнями (см. §4).
10. **Графит + блок графита** — замедлитель. ⚠ Д-8: графитовый пожар (перегрев
    + воздух, Виндскейл) — включать?
11. **ТВЭЛ и капсула** — топливный элемент и герметичная оболочка; цикл §2.2.

### 2.2 Топливный цикл (черновик цепочки)

```
глубиносланцевая урановая руда → уранинит (есть)
  → химзавод: дробление + выщелачивание + осаждение → ЖЁЛТЫЙ КЕК (§2.4 старых записей)
  → фторирование → фторид
  → ОЦФИД каскад → обогащённый материал + отвальный U-238 (броня/экраны)
  → котелок? (литьё) → КАПСУЛА (оболочка)
  → наполнитель: капсула + обогащённый уран → ТВЭЛ
  → РЕАКТОР → отработанный ТВЭЛ (фонит) → БАССЕЙН выдержки
  → хранение (свинцовые ящики) | переработка (МОХ, эпоха 3)
```

### 2.3 Активная зона: качественная нейтроника (числа — автор)

* Сетка ячеек зоны: ТВЭЛ (производство нейтронов ∝ обогащению), замедлитель —
  вода и/или графит, борный стопор (поглощение), теплоноситель.
* Реактивность = производство − поглощение (стопоры, отработка) с учётом
  замедления; режимы: подкритика/критика/надкритика (разгон → перегрев).
* **Связка «обогащение ↔ замедлитель» (предложение):** натуральный уран +
  графит = большой и мощностно-скромный реактор; обогащённый + вода =
  компактный и мощный. Даёт экономический смысл ОЦФИД и правдоподобие 60-х.
  ⚠ Д-4.
* Тепло → теплоноситель → пар; недостаток теплоотвода → рост температуры →
  разрыв контура/осушение → расплав → **кориум** (есть) + радиация (есть).
* Модель детерминированная, сервер-авторитет (урок psyche-аудита).

### 2.4 Управление: поршни и стопоры

* Борные стопоры — блоки в каналах зоны; **ванильный поршень снаружи
  физически задвигает стопор в активную зону** (автор). Следствие для
  валидатора: стопор легален в ЛЮБОЙ позиции канала (правило «любые
  состояния частей» из multiblock_rules §4).
* ● Предложение fail-safe (SCRAM, как в 60-х): без сигнала редстоуна стопор
  возвращается в зону сам (поршень — активное извлечение, гравитация/пружина —
  пассивный возврат). Потеря питания = глушение.

### 2.5 Тепловой контур

Вода зоны → пар (есть) → давление растёт при избытке тепла (§3) → ВД пар
→ усиленные трубы/узлы → потребители (турбина/ступень). Кап отдачи — на узел
(multiblock_rules §7). Автоматизация закладки топлива — спросить (Д-11).

## 3. ВД пар: отдельная жидкость или параметр давления? (автор просил подумать)

**Рекомендация — гибрид, вариант Б (параметр + пороги состояний):**

* Пар несёт **параметр давления** (как солёность воды / гниль сусла — механика
  параметров в моде уже есть). Эффективное состояние дискретно по порогам:
  **пар → ВД пар → СВД пар**.
* Плюсы: одна сущность (не плодить жидкость × трубы × узлы × машины ×3),
  «нагрел сильнее — получил ВД» читается игроком, машины объявляют предел
  давления; превышение → вент/разрыв (в §2.3 старых записей у наполнителя уже
  есть «сверхкритический пар — разрыв» — терминология согласуется).
* Усиленная труба/узел = рейтинг давления (держит ВД); обычная с ВД = авария.
* ⚠ Д-6: сколько порогов и пределы (числа авторские). Вариант А (отдельные
  жидкости) остаётся запасным, если параметр конфликтует с сетевым кодом пара.

## 4. Бассейн выдержки ● (в авторском списке нет, но по фразе «твэлы чиллят
в бассейне» — нужен)

Бетонированный бассейн с водой; отработанные ТВЭЛы лежат в воде N тиков;
без воды — радиационное поле (ChunkRadiationData). Выход: остывший ТВЭЛ →
хранение/переработка. ⚠ Д-7: отдельная структура или зона реакторного здания?

## 5. Дополнения (ответ на «хз что ещё»)

1. Отработанный ТВЭЛ — предмет с `ItemRadioactivity` (система есть); манипуляция
   только щипцами (§2.8) — связывает компонент №2 с реактором.
2. Бассейн выдержки (§4).
3. SCRAM fail-safe (§2.4).
4. Борная кислота в воду зоны — химическое глушение (позднее расширение; бура
   уже есть).
5. Дозиметр + Hazmat уже есть — обслуживание зоны только в СИЗ, панель —
   приборы (реактивность/Т/давление/мощность).
6. Бетон (блок) — радиационная защита, связка с `Containment`.
7. Манометр: давление пара читается компаратором/HUD ключа (читаемость §3).
8. Каскад ОЦФИД: последовательные машины, отвальный U-238 как продукт (броня,
   экраны, балласт).
9. Турбина/ступень под ВД пар или давление-бонус существующей турбине (⚠ Д-9).
10. Графитовый пожар как редкая авария (Д-8).
