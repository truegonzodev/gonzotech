# Заметки учёного

Срез кода: **0.3.311**, `c15083f`; документальная база: `42730c3`. Сверка/миграция: 27.10.2026.


## Прогресс и представление заметок

Здесь описаны книга, страницы, флаги и избранное, а не решатель доски. Техническая доска и подсказки — [CHALKBOARD](CHALKBOARD.md); нумерация открытий и разные гейты — [PROGRESSION](PROGRESSION.md). Общий `PlayerChalkboardProgress` не делает эти интерфейсы одной системой.

`ScholarNotesContent` содержит **51 страницу**, постоянные ID 1…51. Порядок массива PAGES не равен числу ID. Линейные главы и «Познание мира» имеют раздельную навигацию; пустые вкладки поздних глав не означают готовый текст. Локализации — ru_ru/en_us; сетки иллюстраций сверяются с реальными рецептами.

## Избранное и фильтр

Избранное — серверно проверяемый per-player список с сохранением в attachment мира, порядок добавления сохраняется. Фильтр избранного — временный и отдельный для категории, сбрасывается при новом открытии меню. Правая лента флажков 28×14, гэп 4, ограниченный scroll и ARGB fade; маленькие иконки 9×9. Клиент не авторитетен по списку разрешённых ID/прогрессии.

В 0.3.309 страницы 47/48/49/50 используют текст слева и **один** базовый крафт справа, не все вариации. Выходы ×4/×2/×1/×1. Витрина миски включает восемь сырых/жареных продуктов. Некроз — текстовая страница в конце «Познания», гейт **активированное III И факт эффекта**, без изменения радиационного пакета.

В 0.3.310 `page_plain_text.png` автоматически рисуется для TEXT_FULL с телом, перед заголовком/телом с flush между слоями. Порядок: фон главы → шаблон → flush → заголовок/звезда → текст → витрина. PNG автора не переписывать ради тестового фильтра PNG.
