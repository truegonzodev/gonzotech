# Реактор I поколения и топливный runtime

Срез кода: **0.3.311**, `c15083f`; документальная база: `42730c3`. Сверка/миграция: 27.10.2026.


## Границы действующей реализации

Твердотопливный урановый реактор существует: shell/панель/чехлы/клапаны, структурная матрица, runtime ReaCalc-производной модели, GTH-выход, вода, выгорание и аварийная последовательность. Старое «реактор не реализован» из срезов до 0.3.242 неверно для текущего кода. Survival-рецепты деталей ждут сметы D-R2; существование кода не доказывает достижимость в выживании.

Внешний продукт первой архитектуры — **GTH**, не новый пар/GTU. Семь семейств, МОХ/СНУП и физические управляющие стержни не добавляются из старого штурма автоматически. Свинцовые поршни/головки исключены из внутреннего whitelist.

## Структура, топливо, симуляция

- `ReactorStructure` валидирует текущий shell и whitelist; `ReactorMatrix`/`MatrixCoefficients` обслуживают пространственные коэффициенты.
- `ReactorFuelSheathBlockEntity` владеет ItemStacks, панельное GUI проксирует топливо. Количество слотов/распределение и read-only неизвестность не подменять старыми 18-слотными централизованными списками.
- H/L статического структурного слоя и источник текущей загрузки — разные величины. Старое промежуточное «T/S — сила источника» не возвращать.
- `ReactorRuntime` / `ReactorHeatDynamics` / `ReactorOperatingMetrics` / `ReactorHeatOutputCurve` ведут температуру и тепло. Незагруженная топливная зона означает отложенный тик, не нулевое топливо/бесплатную выработку.
- Вода влияет на действующий режим теплопередачи/выработки; фраза ранней 0.3.242 «объём воды ни на что не влияет» отменена в 0.3.244.
- Клапаны выполняют сброс, эффекты и расход по текущим константам. Выгорание активно при реальной выработке; закон ступеней и ресурс сверять по runtime, не по первому черновику.

Текущий масштаб максимальной активной зоны после 0.3.244 — 16³ (внешний корпус 18³); ранние 4–16 shell и строка 15³ в пятилетке не универсальная нынешняя геометрия.

## Аварии и остаточное состояние

С 0.3.246 достижение 10 000 °C запускает аварию; прежнее «не порог аварии» отменено. `ReactorAccidentData` хранит последовательность на уровне, переживая разрушение панели. Пролом связан с горячей точкой; вода/слизь/кориум/лава, взрыв, гейзер и пыль — не условный мгновенный block drop. Сирена/частицы и их поздние уточнения — версия 0.3.247 и соответствующий код.

Последующая ревалидация клетки/чанка, приём угля, отмена при недоступной зоне — исправления 0.3.306. Не объявлять их отсутствующими по ранним концептам. Честная игровая приёмка конкретного сценария отделена от source-пина.

## Топливный цикл

`uranium_fuel` + оснастка пресса → `uf_tvel` → чехол → `depressed_uf_tvel`. Пресс выполняет роль старого закатного станка. Обычный измельчитель даёт крайне опасные шлаки; III-измельчитель с пустым корпусом даёт умеренные шлаки/бочку. С 0.3.253 разделение обоих шлаков — ПЦФСОЗ. Природное уран/торий-топливо ядерной топки — другой потребитель; изотопы и смеси не следует разрешать в топке для замыкания реакторного цикла.

Дальнейшие предложения — [reactor_extensions_concept](reactor_extensions_concept.md), открытые конкретные задачи — D-R2/R6/R7/R8 в [DEFFERED](DEFFERED.md).

Уточнение автора в DOC-002: **4…18 — абсолютный внешний размер с обшивкой**, **2…16 — размер внутреннего ядра по стороне**. Старый class-comment «4..16» не задаёт текущий предел; код/валидатор допускают 18 снаружи.

Тип поведения — **реакторный, «живёт сам по себе»**: loss of formed очищает порты, но не уничтожает тепло/ресурсы/последний snapshot. При живой панели и saved bounds/snapshot возможна остаточная симуляция, без штатного портового I/O и без выгорания топлива через formed-guard `ageLoadedFuel`. Сломанная панель может оставить ReactorEmberData. Это не симуляция выгруженных чанков. Сравнение с классической турбиной — [MULTIBLOCK](MULTIBLOCK.md#два-утверждённых-типа-поведения). Код не менялся.
