Первые шесть идут именно в этом порядке между «Редстоун и лава» и «Цезий»;
существующий «Вольфрам» остаётся на своём месте перед ними. «Некроз» — в самом
конце «Познания», строго текст, без витрины и иллюстрации. Для некроза проверяется именно
активированный recipe tier III, а не прежний флаг простого получения свитка.
Остальные страницы
содержат текст и витрины относящихся к теме предметов. Есть RU/EN-тексты.

`NotesKnowledgeEvents` наблюдает успешный pickup и `MobEffectEvent.Added`,
фиксирует флаги в прогрессе игрока. Раз в секунду подхватываются уже имеющийся
некроз/булыжник старого сохранения; после получения флага повторного скана
инвентаря ради булыжника нет. Пороги времени публикуются при их пересечении;
открытие меню также запрашивает свежий снимок. Ушедший эффект/израсходованный
булыжник не закрывают страницы обратно. Механика некроза/радиации не менялась.

Существующие ID **1..44 не перенумерованы**. Оглавление теперь содержит 51
страницу; порядок массива не равен ID. `ScholarPage.number` — постоянный
идентификатор для сохранения, а счётчик в GUI по-прежнему считает видимые
страницы текущей книги/выборки. Триггер клипа «Зарисовки» остаётся на ID 38.

## Избранное: сохранение и сервер

- Поле `favoriteNotes` в `PlayerChalkboardProgress.CODEC`: упорядоченный список
  ID, необязательное поле с пустым значением для прежних сохранений.
- Используется существующий персистентный **per-player attachment** в сохранении
  мира. Не файл конфигурации клиента. Сохраняется при смерти (`copyOnDeath`),
  выходе, перезапуске сервера; у другого игрока/мира свой список.
- Добавление дубликата ничего не переставляет. Удаление и повторное добавление
  ставят страницу в конец. Неизвестные ID не принимаются.
- C2S передаёт `(pageId, favorite)`, то есть намерение установить состояние,
  не команду «переключить». Повторный пакет не отменяет предыдущее действие.
- Сервер проверяет ID, гейт добавляемой страницы и rate-limit, записывает
  attachment, отправляет авторитетный снимок. Удаление возможно даже после
  debug-сброса гейта; сам список от закрытия гейта не теряется.
- Снимок избранного ограничен количеством существующих страниц.
  Клиентский кэш очищается на выходе из мира/сервера.

## Избранное: экран

- После заголовка — **9×9 UI px**. Для длинного заголовка оставляется место под
  звезду; текст при необходимости сокращается многоточием. На страницах без
  заголовка звезда занимает начало заголовочной строки.
- `feature_icon.png` — добавить; `featured_icon.png` — уже добавлено.
- ЛКМ добавляет/удаляет текущую страницу, ПКМ переключает фильтр текущей
  категории. Все четыре сочетания tooltip: белый заголовок + две серые строки
  с точными действиями ЛКМ/ПКМ, без буквальных `/n` или цветовых амперсандов.
- Фильтры — обычный `EnumSet` **экземпляра Screen**, не сетевой и не сохранённый
  параметр. Категории независимы. Повторное открытие книги показывает всё;
  повторный ПКМ снимает фильтр. Изменение GUI-масштаба не обнуляет фильтр.
- Пустой фильтр показывает сообщение и `0 / 0`; звезда остаётся доступна,
  чтобы снять фильтр или добавить страницу. Вкладка категории не становится
  «закрытой» из-за пустого избранного.
- Справа — общая лента всех доступных избранных страниц, в порядке добавления,
  не только текущей категории. Каждый флажок имеет tooltip с заголовком.
  ЛКМ **или** ПКМ по флажку сразу открывает его страницу через существующий
  `gotoPage` (в том числе сбрасывает прокрутку текста/подстраницу структуры).
- `notes_favorite_tab.png`: **28×14**, гэп **4 UI px**. Шесть пикселей уходят под
  рамку, как у левых вкладок. При высоте окна 200 px видны 11 целых флажков и,
  при переполнении, часть следующего.
- Колесо над правой лентой имеет приоритет над прокруткой текста. Прокрутка
  ограничена `[0, maxScroll]`, без зацикливания. Прямоугольники клика ограничены
  видимой областью и не проходят сквозь рамку.
- Градиент прозрачности — построчный ARGB в вершинах `GuiGraphics.blit`, не
  `RenderSystem.setShaderColor`: на GUI 1.21.4 последний не давал нужной альфы.
  Верх затухает только при наличии содержимого выше, низ — только если ниже
  осталось содержимое. Короткий список вообще не затухает.

Плейсхолдеры лежат в `assets/gonzotech/textures/gui/notes/`; их можно заменить
авторским PNG, сохраняя указанные размеры и имена.

### Чеклист авторского прогона

1. Креатив: семь перечисленных блоков ровно по разу, после крана, не среди II.
2. Новое/старое сохранение: до часа страницы 45–48 закрыты; с часа открыты.
   Миска — только с двух часов. Булыжник открыть и расходовать: монолиты остаются.
3. Некроз без открытия III / открытие III без некроза — страница закрыта;
   оба факта в любом порядке — открыта в конце «Познания», только текст.
4. Звезда: все четыре tooltip, ЛКМ add/remove, ПКМ фильтр только категории.
   Удалить последнее избранное под фильтром; снять фильтр; закрыть/открыть книгу.
5. Избранное: выйти/войти, умереть, перезапустить сервер — список/порядок на месте.
   Другой игрок и другой мир не получают этот список.
6. 10, 11, 12 и больше флажков: начало/середина/конец, градиент с нужных сторон,
   без клика по невидимому. Колесо над лентой не прокручивает текст.
7. ЛКМ/ПКМ флажка: переходы между обеими книгами, страницы без заголовка,
   длинный заголовок, страницы со структурами и клипом; изменение GUI-масштаба.
