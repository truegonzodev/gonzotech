# ГОСТ единиц: разбор форматов и что уже покрашено (22.09.2026)

Задача автора: «единицы GTU/GTH/вода/пар/предметы всегда своего цвета — в GUI, тултипах, HUD,
подсказках, ключах; радиация всегда `#ceeb2d`, токсичность всегда `#d12176`; формат
`<цвет>[число] [единица]<&7 или &f>/t`; шкалы не трогать; спарсить форматы и прислать».

Ниже — **разбор того, что реально было в коде** (все форматы с единицами), **что стало** и
**что осталось незакрытым**.

---

## 1. Палитра (взята из подсказки гаечного ключа)

| обозначение | цвет | где был источник |
|---|---|---|
| GTU | `#FFD84A` | `PipeType.WIRE` (провод) |
| GTH | `#FF6A4A` | `PipeType.HEAT` (теплотруба) |
| вода | `#4AA3FF` | `PipeType.WATER` |
| пар | `#D8D8D8` | `PipeType.STEAM` |
| предметы | `#C08A4A` | `PipeType.ITEM` |
| радиация | `#ceeb2d` | задано автором (не из ключа) |
| токсичность | `#d12176` | задано автором (не из ключа) |

Цвета теперь живут **в одном месте** — `core/text/GtUnits.java`. `PipeType.color()` берёт их оттуда
же, поэтому «цвет трубы» и «цвет единицы» физически не могут разъехаться.

## 2. Формат (как в ГОСТ-задании)

```
<цвет>[число] [единица]<основной цвет>/t
```

* **число и обозначение** — цветом единицы;
* **хвост времени** (`/t`, `/s`) — НЕ красится, наследует основной цвет строки: в тултипах это `&7`,
  на HUD — `&f`, в чате — цвет сообщения. Это реализовано буквально: хвост живёт в lang
  (`unit.gonzotech.per_tick` = `/t` / `/т`, `per_second` = `/s` / `/с`) и вставляется компонентом
  без стиля.

Жирным ниже помечено то, что теперь **красится**; хвост `/т` намеренно остаётся основным цветом.

## 3. Что было и что стало

### 3.1. Тултипы станков — пары «значение / ёмкость» (19 экранов)

Формат был один и тот же: подпись + два числа, единица — либо в подписи, либо в хвосте строки.
Числа печатались как `int`, то есть вообще без цвета.

|---|---|---|
| котёл, огневая топка, ядерная топка, парогенератор | `GTH: 12 / 100` | **GTH**: **12** / **100** |
| аккумулятор (+II), дробилка, помпа (+II), электропечь (+II), генератор булыжника (+II), центрифуга, сплавная печь, пресс, шлифовальня, турбина, Стирлинг | `GTU: 12 / 100` | **GTU**: **12** / **100** |

| котёл, парогенератор, Стирлинг | `Пар: 12 / 100 mB` | **Пар**: **12** / **100 mB** |
| турбина | `Пар турбины: 12 / 100 mB` | **Пар** турбины: **12** / **100 mB** |

## 4. Что найдено разбором, но НЕ тронуто (осознанно)

1. **Шкалы HUD** — заливка и подпись, появляющаяся после 10 %: по указанию автора шкалы не трогаем
   (в том числе цвет заливки радиации `#8df542`, который отличается от «текстового» `#ceeb2d`).
2. **Проценты и не-единицы**: прогрессы (`Переработка: 42 %`), КПД конденсата, ядра/обменники
   парогенератора, роторы турбины, `Day: … · Efficiency: …`, `Speed - 4.3 blocks/sec` (спидометр),
   `Ожог: 12 %` (ядерная топка). «blocks/sec» в список единиц не входит — если надо, покрашу.
3. **Доза в отчётах приборов** — цвет по категории (это статус, не единица).
4. **Лор «Заметок учёного»** — там `**GTU**`/`**GTH**` встречаются как слова в письмах; это
   художественный текст, слова внутри абзацев не красил.

## 6. Вопросы

**Закрыто автором 22.09.2026 (вечер, дословно: «ГОСТ! Пробел везде "[число] [единица измерения]/[делитель временной]"»):**

1. ~~Пробел перед единицей~~ — **пробел везде**, слитной формы нет нигде: сканом проверены
   все `%s`-шаблоны lang и все `literal(...)` с единицами в java — 0 слитных вхождений.
   `30 mZt/т`, `12 GTU/т`, `1000 mB/т`.
2. ~~Предметная труба: слово-единица~~ — **единица видна**: `Булыжник — 16 items/т`
   (`GtUnits.rate(count, key(U_ITEMS, …))` в HUD ключа; слово «items» — из lang, в обеих локализациях).

**Ещё открыто:**

3. **Цвет подписи-слова.** «Вода», «Пар», «Кипяток», «Конденсат», «GTH» покрашены в цвет ресурса —
   иначе строка «рассыпается» и единица выпадает из общего вида. Если хочется строже — оставлю
   серыми подписи, цветными только числа и обозначения.
4. **Хазмат-тултип** — подключать (см. §5)?

## 7. Как добавить новую единицу (для будущих механик)

```java
// 1. цвет и обозначение — в GtUnits (единый источник)
public static final int FOO = 0x00FF00;
public static final String U_FOO = "resource.gonzotech.foo.unit";   // «Foo» в lang

// 2. строка — из кирпичиков
GtUnits.rate(value, GtUnits.key(GtUnits.U_FOO, GtUnits.FOO), GtUnits.FOO)  // «12 Foo/t»
GtUnits.amount(value, ...)                                                 // «12 Foo» (склад)
GtUnits.pair-подобные обёртки — по образцу gtuPair()/waterPair()
```

`num(value, color)` — число цветом, `ticked(value, color)` — «12/t» (когда обозначение стоит в подписи).
Шкалы, прогрессы и проценты остаются вне ГОСТа — у них своя палитра.
