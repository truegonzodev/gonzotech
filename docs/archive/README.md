# Архив документов Gonzo Tech

Эти файлы **закрыты** и оставлены только как история решений: они описывают состояние на момент
написания и с тех пор разошлись с кодом (переименования, новые подсистемы, локализация).

**Радиация на 27.10.2026 / 0.3.311:** авторский `c15083f` уже интегрирован.
Архивные NBT/tooltip/пороги относятся к прежним версиям. Динамические rate/tick
теперь вне ItemStack, сохранение — owner sidecar, вывод — отдельная панель.
[Действующая спецификация](../ITEM-RADIATION-CURRENT.md).
Замороженные файлы архива намеренно не переписываются.
