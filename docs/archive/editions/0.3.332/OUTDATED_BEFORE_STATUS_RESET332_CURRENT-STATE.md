#### 9. Настоящая ownerless WorldGuard-интеграция

**Реализовано в332; не закрыто по игре.** Bridge выбирают создатели серверов. Target автора — WG7.0.13 / WE7.4.2 либо подходящая7.4.x на Bukkit/Paper1.21.4; универсальная совместимость не заявляется. Реального hybrid-стенда пока нет по ответу автора.

Проверяется только **клетка фактической предстоящей правки**, никогда блок самого Плотника; нет предварительного region-scan всего3×3. Охвачены рабочие блоки/буры, установка и замена бур-трубы с добычей породы, боковой всос руды, демонтаж, замена на TNT — до расхода/правки/выдачи, с прежними очередями/retry.

Для **любой** правки нужны оба разрешения `block-place` и `block-break`: каждое — явный ALLOW либо, при UNSET, fallback от `build=ALLOW`. Любой явный DENY place/break запрещает всё; `build=DENY` — безусловный машинный veto. `pistons` обязан быть **явно ALLOW**; UNSET запрещает, хотя стандартный default WG равен ALLOW. Полное отсутствие этих флагов внутри региона не разрешает работу. Приоритеты, одинаковые priority, родители и region groups разрешаются движком WG; субъект всегда NON_MEMBER, без владельца/ближайшего игрока.

`__global__` считается регионом всего мира, не «вне регионов». По отдельному решению автора явный глобальный `build=ALLOW` **может дать fallback**, в отличие от legacy-правила самого WG. Исключение учитывает NON_MEMBER-группу и native priority/ignored-parent/implicit-build barriers: не перепрыгивает локальный build-барьер и не отменяет DENY/прочие флаги. Остальные значения разрешает WG.

Без WG — штатные NeoForge-события/их прежний кэш, без новых region/world scans; вне всех регионов — разрешение. Известный установленный, но disabled/неисправный WG/WE/API/world mapping/region data — отказ с bounded-диагностикой, не actor fallback. Правки флагов и замена RegionManager видны при следующей попытке даже в том же тике. [Полный контракт/серверный чек-лист](INTEGRATIONS.md#perf-001-wg332).

Проверка: production adapter/policy/session + неизменённые BE gate/mutation bodies,1326assertions/9mutants/exact331negative;100000absentAPIcalls без block/chunk reads. Настоящий WG7.0.13 flag engine в plugin-only classloader; Bukkit/MC/геометрия/Guava — doubles. Это **не** full MC/Gradle/GameTest/native hybrid/playtest/TPS;9 остаётся открытым до игрового подтверждения.
