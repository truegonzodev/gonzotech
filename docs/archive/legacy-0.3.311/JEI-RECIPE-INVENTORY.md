# JEI-рецепты для проверки в игре

Срез по исходникам версии **0.3.226**; актуальная сверка счётчиков и пробелов перенесена в пункт Е5 [Пятилетки II](PIATILETOKA-2026-10-26.md) (с 0.3.226 добавились ПЦФСОЗ-шлаки 0.3.253, топлива ядерной топки, измельчитель II). Счётчик — число отображаемых JEI-записей, а не количество вариантов предмета внутри слота. Альтернативы, которые JEI циклически показывает в одном слоте, считаются одной записью. Это display-only список для проверки; он не меняет машинную механику.

**Сумма фиксированных машинных и крановых записей:** **292**, без двух электропечей и без текстовой категории. Если в загруженном наборе ровно `N` рецептов `SMELTING`, к ним добавляется `2N` записей электропечей. Точное `N` определяется игровым `RecipeManager` и не зафиксировано в Java-таблицах проекта.

## Текстовая категория

| Категория | Записей | Содержимое |
|---|---:|---|
| Багровый обсидиан | **1** | Только заданный текст о соприкосновении лавы и блока красного камня; видимых слотов нет. |

Итого фиксированных записей, включая текстовую категорию: **293**, плюс `2N` записей электропечей. В реестре **23 категории**: 21 машина/генератор, разливной кран и текстовая запись.

## Примечания к счёту

- У дробилки 46 записей для рудных блоков GonzoTech, потому что один тип руды может иметь несколько host-блоков. Это 26 типов руды, а не 46 разных металлов.
- У шерсти, центрифужных вариантов raw/host и входных форм сплавов несколько предметных альтернатив внутри JEI-рецепта; они не умножают число записей.
- У SteamGen шесть фиксированных контрольных профилей на один сердечник. Они используют расчёты `SteamGenMath`; профиль на цикл нельзя трактовать как гарантированную длительную скорость через ограниченные fluid I/O-порты.
- Категории открытия/ванильного крафта не включены в этот машинный перечень. JEI-рецепты не скрываются.
