# История дюпа: симптом → лечение → вердикт → оценка

GonzoTech 1.21.4, 0.3.249 … 0.3.279. Один файл, вся эпопея от первого
«саморазряда-бесконечки» до закрытия выживания 24.10. Имя файла: автор писал `dupe_cruing.md` — очевидно, опечатка вместо
`curing`; файл назван `dupe_curing.md` (переименовать — секундное дело).

## Протокол доказательства (константа автора, 23.10)

Дюп считается доказанным **только** если выполнены оба условия:

1. **Рост количества на сервере** — сумма предметов (Σшт) у сервера увеличилась
   сама, а не «картинка у клиента» (инструменты: `[RAD-INV]` дельта на клик с
   0.3.272, `[LEDGER]` сервер↔клиент с 0.3.277, мировая Σ с землёй с 0.3.278).
2. **Перезаход** — лишнее количество стабильно после переподключения к серверу.

Всё, что не прошло оба фильтра, — призрак синхронизации или механика режима
(креатив). Инструменты безусловны: доказывать живость самого зонда, а не
объяснять его молчание отсутствием события.

## Что живёт в коде как защита (активное «лекарство»)

- **Тик-бэкстоп раздутых стаков** (с 0.3.276): стаки открытого меню + carried
  сверх `slot.getMaxStackSize(stack)`/предметного лимита срезаются на месте с
  WARN `[RAD-INV] ... раздутый стак` — вторая линия, не зависящая ни от какого
  миксина.
- **Held-запись каждый проход + трипwire причин** (0.3.275) — против «мгновенных
  потерь» наведёнки.
- **`[LEDGER]` мировая Σ** (0.3.278): `меню Σ | клиент Σ | расхождение | земля Σ
  (N сущ.) | мир Σ` — физический дюп = рост мировой Σ без легитимной причины;
  переживает перезаход по определению (меню-часть).
- **Unconditional-пробник кликов** (0.3.277): «обработчик кликов жив: клик №N» —
  живость канала доказывается всегда, без конфиг-гейтов.
- **Отсутствие пауз**: любые freeze-гарды запрещены решением автора (23.10).

## Припарковано (не чиним, осознанно)

- **Креативный slot-interaction / drop-dupe** (автор 24.10 подтвердил живым).
  `CreativeMenu`-слоты не подчиняются инвариантам
  контейнеров (выделенное + колесо, middle-click-набор, drop-магия) — это
  штатный инструментарий творческого режима, серверное `HandleCreativeMode`
  принимает что может. Если понадобится — отдельное решение автора
  (например, запрет наших gui-слотов в креативе); по умолчанию паркуем.
- N1 (mZt-перекалибровка формул, python-sim), N4 (bundle copy), N5/N6/N7/N11 —
  из общего плана аудита, к дюпу отношения не имеют.
- Блокеры по-прежнему: #7 (region-flag source), #23 (продолжение топлива).

## Уроки эпохи (процессные)

1. Дюп доказывается серверной дельтой количества + перезаходом; «выглядит как
   дюп» — не аргумент.
2. Молчание инструмента ≠ отсутствие события; живость зонда доказывается
   unconditional-строкой, конфиг-гейт для диагностики — антипаттерн.
3. Вывод об имени метода вани — только после чтения его тела (эпопея 276 с
   «всасыванием» стоила раунда).
4. Заморозки/паузы — вмешательство в физику ради диагностики; диагностика
   обязана быть наблюденияем, а не лечением-в-слепую.
5. Отрицательный результат — результат: 277/278 закрыли каналы «доказано, что
   не наши», и это ровно то, чего просил протокол.
