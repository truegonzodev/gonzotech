## 1. Главный вопрос: контур из РАЗНЫХ блоков в перемешку

Короткий ответ, потом формулы.

> **Сегодня** контур считается не «по слабейшему звену» и не «по сильнейшему», а
> **средневзвешенно по площади внутренней поверхности полости** — то есть стена «в перемешку»
> ведёт себя как её средний состав. **Дописать надо три вещи:** слои должны умножаться (сейчас
> считается только внутренний слой), толщина должна работать (сейчас 1 блок = 10 блоков), а двери и
> проходы должны быть честными дырами (либо получить свой коэффициент, либо гермоввод).

### 1.1 Как это работает СЕЙЧАС (по коду, а не по памяти)

`radiation/Containment.java`, метод `probe(level, source)`:

1. Из точки источника делается **BFS-заливка полости** по проходимым клеткам (до 2048 клеток,
   радиус 32).
2. Если заливка **вырвалась на простор** — `фактор = 1.0` (контура нет, фонит как обычно).
3. Если заливка уперлась в оболочку целиком — собираются все **клетки-стенки**, и результат:
   `фактор = Σ(прохождение клетки) / (число клеток)`. То есть **среднее арифметическое**, где
   каждая клетка = единица площади.

Коэффициенты клеток — `radiation/RadMaterials.blockFactor` (id-путь блока):

| материал | прохождение |
|---|---|
| вольфрам | 0.003 |
| ВР-20 | 0.01 |
| **бариевый бетон** (точечно, блок) | **0.01** |
| свинец | 0.02 |
| барий | 0.02 |
| осмий / иридий | 0.05 |
| **боро-стекло** (точечно, блок) | **0.05** |
| бор | 0.13 |
| литий / магний / цинк | 0.2 |
| железо, медь, олово, никель, кобальт, хром, марганец | 0.5 |
| прочие металлы (сталь, титан, алюминий, золото…) | 0.3 |
| всё остальное (камень, земля, дерево, **обычный бетон**) | 1.0 |

Результат кэшируется по позиции на 20 с и используется в `ChunkRadiationData` (пластовые
заражения: «поставленные радио-блоки» подтягивают заражение чанка к своей эмиссии × фактор).

### 1.2 Что это даёт на цифрах (комната, полость 5×5×5 = 150 клеток поверхности)

| стена | утечка | смысл |
|---|---|---|
| весь вольфрам | **0.003** | 0.3 % уходит |
| весь свинец | 0.02 | 2 % |
| весь бариевый бетон | 0.01 | 1 % |
| **половина вольфрам, половина свинец** | **0.0115** | ровно между ними (взвесили по площади) |
| весь вольфрам, но 1 клетка земли в потолке | 0.0096 | дырка в 1/150 площади портит в 3 раза |
| весь вольфрам, но 2 клетки двери без своих свойств | **0.0163** | **дверь «съедает» больше, чем все стены вместе** |
| стальные стены | 0.5 | сталь почти прозрачна для гаммы |
| камень / земля | 1.0 | герметично, но НЕ экранирует (так и должно быть) |

Вывод, который важно принять осознанно: **смешивать материалы в одной стене можно и полезно**
(дешёвый свинец + вольфрам в самых горячих местах), но **всё решает не «перемешка», а дыры**:
одна дверь без свойств в вольфрамовой комнате даёт утечку больше, чем все стены вместе.

### 1.3 Шесть правил, которые предлагаю закрепить

| № | правило | состояние |
|---|---|---|
| 1 | **Замкнутость.** Любая дыра — открытая дверь, проём, труба насквозь — снимает контур целиком (`1.0`). | ✅ уже так |
| 2 | **Материал в слое — по площади.** Перемешка = средневзвешенная доля прохождения. | ✅ уже так |
| 3 | **Слои умножаются.** Внутренняя обшивка, потом бункер, потом ящик — произведение. | ⚠️ **дописать** |
| 4 | **Толщина.** Прохождение считать вдоль луча наружу, перемножая клетки: 1 блок вольфрама 0.003, три блока — 0.003³ = 2.7·10⁻⁸. | ⚠️ **дописать** |
| 5 | **Двери.** Заслонка **не участвует в расчёте вообще**: она только удовлетворяет условию «контур закрыт» (автор 22.09). Реализовано через тег `contour_seal` + состояние `open`. | ✅ **реализовано** |
| 6 | **Проходы = дыры.** Труба/провод/вентиляция сквозь экран размыкают контур. Отдельного блока-гермоввода НЕ будет (автор 22.09: «гермоввод — это просто буфер из двух гермодверь, где стоят очистители») — то есть вопрос закрыт конструкцией, а не новым блоком | ✅ решено автором |

Плюс два следствия:

* **Численный порог.** Предлагаю: если итоговый фактор ≤ 10⁻³ — писать «0» (дозиметр показывает
  прочерк, заражение чанка не растёт). Тогда твой расчёт «округлено до нуля» работает формально,
  а не «почти ноль».
* **Видимость.** Перемешка и толщина невидимы игроку, если их не показать. Предлагаю: дозиметр при
  прицеливании на стену/источник показывает строку утечки контура (по ГОСТу, своим цветом), плюс
  страница заметок с формулой. Иначе это арифметика «в столе».

### 1.4 Дверь — решено автором (22.09)

Дословно: «Дверь не имеет свойств я имел ввиду что она считает контур закрытым и всё. Это не
среднее между 0.02 и 1.0. А как бы **дверь вообще не участвует в расчётах**, она просто выполняет
условие закрытого контура (если других дыр нет)».

Это ровно то, что просил математически: клетка-заслонка **не входит в среднее** — она не тянет
фактор вверх (как 1.0) и не отнимает площадь у экранирующих стен (как если бы считалась «своей»).
Открытая дверь при этом честная **дыра**: контур разомкнут, фактор 1.0.

Реализация: тег `gonzotech:contour_seal` (пока пуст — тяжёлой двери нет) + правило «закрытость
ищем по булеву состоянию `open`». Антиэксплойт: если заслонок больше половины оболочки, они
считаются обычными стенами — иначе «стена из дверей + один блок вольфрама» давала бы бесплатный
контур. Подробности и таблица цифр — в аудите §9.40.

### 1.5 Ящики (свинцовый 0.10 / вольфрамовый 0.03) — как считать

Твой расчёт сходится, но только с Правилом 3 (слои умножаются):

```
свинцовый ящик 0.10 × бариевый бункер 0.01 = 1.0·10⁻³
вольфрамовый ящик 0.03 × бариевый бункер 0.01 = 3.0·10⁻⁴
```

Это 1000–3000-кратное падение эмиссии: дозиметр на дистанции не видит ничего, чанк не набирает
заражение — «округлено до нуля» ровно как ты посчитал.

Техническая честность: **содержимое контейнеров в мод уже считается** — `RadiationSystem.scanContainersInto`
обходит `Container`-блок-сущности активного чанка и берёт эмиссию содержимого × `Containment.factor(pos)`
(свинцовый купол над сундуком с ураном уже гасит вклад, автор 21.09). Значит ящикам нужен только
**свой множитель материала** (0.10 / 0.03) поверх контура:

* ящик = блок-контейнер; раз в N секунд (редко) обходим его слоты и считаем **Σ эмиссий содержимого**;
* эта сумма идёт в чанк как «поставленный источник» в позиции ящика, **с множителем 0.10 / 0.03**;
* поверх — `Containment.factor` от позиции ящика (будка/бункер).
* Антиэксплойт: ящик в ящик не кладётся; вложенные контейнеры внутри не считаются (иначе —
  бесконечный «матрёшка-щит»).

### 1.6 План доработки `Containment` (Containment 2.0)

1. `probe` → `probeShell` (заливка как сейчас) + **`depthWalk`**: от клетки стенки идём по нормали
   наружу до воздуха, перемножая факторы (обычный солид = ×1.0, кап 8 клеток).
2. **`peel`**: после первого слоя заливаем *наружную* полость от стенок; если она упирается в
   материал — это второй слой, умножаем; если вырывается на простор — второго слоя нет. Максимум 3 слоя.
3. **Порог**: `фактор < 10⁻³ → 0` (с сохранением «есть контур / нет контура» раздельно).
4. Таблица `RadMaterials`: добавить двери, гермоввод, новые сплавы (ВР-20, кантор/витрелой/стеллит —
   если решаем, что топовые сплавы тоже экранируют).
5. Тяжёлая дверь: блок с состоянием «открыта/закрыта»; закрытая = замыкающая клетка, открытая = воздух
   (контур разомкнут). Буфер-тамбур из двух дверей: контур закрыт, когда закрыты **обе**.
6. Стоимость: 2–3 заливки вместо 1 на источник раз в 20 с, кап 2048 клеток, кэш как сейчас —
   по нагрузке это по-прежнему копейки.

## 2. Машины базы: разбор по пунктам

### 2.1 Химический завод (крафтер/трансмутатор: GTU + вода + GTH)

**Что уже есть, чтобы не плодить системы:** `machines/processing/AlloyRecipeRegistry` +
`AlloyMaterialCatalog` — это уже готовый **data-driven реестр «предметы + жидкость + GTH + GTU →
предмет/жидкость»** (на нём работает завод сплавов). Химический завод — тот же формат рецептов,
другая таблица. Ничего нового по архитектуре не нужно.

**Что он должен делать (по твоим словам + что напрашивается):**

* **Препараты** (§11.1): промежуточные — аминоблейзатанол, цианат натрия, **ЭДТА** (формальдегид +
  лазурит), формальдегид, хлорид кальция; далее Цистамин / Пентацин / ДТПА.
* **Химия литографии**: фоторезист, проявитель, травитель, растворители.
* **Обогащение**: выщелачивание руды → **жёлтый кек** (U₃O₈) → фторид урана (см. 2.4).
* **Топливная керамика**: спекание порошка UO₂ для ТВЭЛов (мост к реакторам).

**Катализаторы — применение «спящим» металлам.** Отдельный слот: никель, платина, палладий,
рениевая сетка, серебро. Катализатор **не расходуется, но изнашивается** (NBT «износ»), и его
наличие — условие части рецептов. Так никель (16 рецептов), платина и палладий (только руда)
получают настоящую роль.

**Опасность — как у всего в этом моде:** неверный рецепт/перегрев → выброс токсичного облака
(токсичность и Некроз уже есть), при совсем дурном сочетании — пожар. «Химия — это не крафт-стол».

**Вопрос:** химзавод у тебя сам «поднимает» препараты, то есть препараты выходят из статуса
«отложено» — их применение я предлагаю через **ампулы** (см. 2.3). Нужно твоё подтверждение.

### 2.2 Химический реактор (сосуд, не крафтер)

Раз ты назвал его отдельно — предлагаю чёткое разделение, чтобы блоки не дублировали друг друга:

| блок | что это | аналогия |
|---|---|---|
| **Химический завод** | сборка по рецепту: ингредиенты → продукт (мгновенно/быстро) | верстак с теплом и током |
| **Химический реактор** | **сосуд**: залил жидкости, поднял температуру/давление, выдержал время → продукт | автоклав/котёл |
| **Наполнитель** | фасовка и хранение: перелить, упаковать в ампулу, отдать в трубу | фасовочная линия |

Реактор нужен там, где важна **выдержка под давлением**: полимеры для литографии, фториды, топливная
керамика, «варка» сплава под давлением, очистка спирта в ректификаторе (см. 2.7 — либо отдельный блок).
Параметры: температура (GTH), давление (растёт от пара/реакции), объём, катализатор, время.
Если давление выше предела материала корпуса → **разрыв** (взрыв + облако).

**Вопрос:** подтверди разделение или скажи, что реактор и завод — одно и то же.

### 2.3 Наполнитель (универсальный бак с ценой)

**Твоя идея принята целиком** — именно «принимает любую жижу в один бак» и есть его соль. Механика:

* **Хранение/передача**: одна ёмкость, любые жидкости (вода, пар, жидкие металлы — натрий, свинец-висмут,
  расплав соли, кориум, химия), слив в трубы/вёдра/канистры.
* **Таблица несовместимостей** (это и есть опасность):

| что смешалось | последствие |
|---|---|
| вода + щёлочноземельный металл (натрий, литий, магний, кальций) | H₂ + тепло → взрыв, ожог, пожар |
| вода + расплав соли / раскалённый металл | «паровой хлопок» (мгновенный пар → разрыв бака) |
| вода + кориум | паровой взрыв + кориум разлёт + заражение чанка |
| кислота + щёлочь | вскипание, облако, порча бака |
| сверхкритический пар | разрыв, если температура/давление выше предела корпуса |
| радиоактивная жижа (кек, раствор, соли) | бак **заражается навсегда** — фон от него в чанк, и всё, что через него пройдёт |

* **Ампулы**: наполнитель — **единственное** место, где можно безопасно вскрыть/наполнить ампулу
  (йод, цезий, стронций, препараты). Открыл руками — доза/токсичность в руки. Это и есть механизм
  применения препаратов: **(база → препарат) + (наполнитель → ампула/шприц) → применил**.
* **Визуализация опасности**: корпус бака меняет цвет/частицы по «температуре» и «заражению NBT»;
  на HUD гаечного ключа — шкала давления и «что внутри» (свои цвета по ГОСТу).

### 2.4 ПЦФОЗ (продвинутая центрифуга обогащения) + жёлтый кек

**Главная находка:** изотопы в моде **есть как предметы, но не имеют ни одного рецепта** —
`uranium_235`, `uranium_238`, `uranium_233`, `weapons_plutonium`, `plutonium_238/242`, `thorium_229`
зарегистрированы и фонят (`RadSources.DIRECT_EMISSION`), но в игре их **нельзя получить никак**.
То есть ПЦФОЗ — это не «ещё одна центрифуга», а **единственная дверь в изотопный мир** и заодно
ключ к реакторам.

**Цепочка, которую предлагаю:**

```
урановая руда → (химзавод: дробление + выщелачивание + осаждение) → ЖЁЛТЫЙ КЕК (U₃O₈)
              → (химзавод/реактор: фторирование) → фторид/гексафторид
              → (ПЦФОЗ: абразив + фильтры + вода + GTU) → U-235 ↑ / U-238 ↓
ториевая руда → ... → Th-232 → (реактор, трансмутация) → U-233
```

**Механика разделения — каскад, а не рулетка.** Природный уран = 0.7 % U-235; один проход даёт
слабое обогащение, нужно **несколько проходов/последовательных ПЦФОЗ**, чтобы дойти до реакторного,
и ещё больше — до оружейного. Игрок строит каскад и настраивает его (скорость, расход воды).
Расходники: **абразив** (корунд/карбид кремния — кварц + уголь), **фильтры** (забиваются, NBT
«засорён на X %»), **вода**. Общий фильтр — один предмет для химзавода/обдувателя/ПЦФОЗ.

**Побочные продукты = применение:** обеднённый уран (U-238) — в броню/сталь/экраны; фториды — в
литографию; радий/рений — в приборы. **Работать с кеком и изотопами нельзя голыми руками** — вот
здесь и нужны щипцы + ящики (2.8, 2.9): эмиссия U-235 0.10 mZt, U-233 1.50, оружейный плутоний 1.20,
Pu-238 12.0 — это то, что убивает без защиты.

**Ответ автора 22.09:** ПЦФОЗ — **отдельный станок**. Значит `second_centrifuge` остаётся рудной
(пыль/концентрат), ПЦФОЗ — изотопная (суспензия/газ). Существующие рецепты не ломаем.

### 2.5 Закатной станок (герметизация)

Предлагаю три роли, из которых главная — **ТВЭЛы**:

1. **Капсулы ТВЭЛов**: трубка (цирконий/нержавейка) + топливная керамика + закатка торцов →
   герметичный ТВЭЛ. Незакатанная капсула фонит и «течёт» (доза в руки, заражение пола).
2. **Ампулы**: закатка ампул с йодом/цезием/стронцием (пара к наполнителю: он наливает, закатной
   закрывает).
3. **Канистры и банки**: канистры для агрессивных жидкостей (натрий, расплав соли) и **пищевые
   консервы** (долгое хранение еды — приятная бытовая ветка).

Реализация простая: машина-пресс с расходником (крышки/кольца) и слотом инструмента.

### 2.6 Сусловарение (веха): чан → бродильный бак → дистиллятор → ректификатор

Цепочка «как надо» и гейт по §15.6 (**после 2–3 Открытия**):

| блок | что делает | примечание |
|---|---|---|
| **Чан (котёл)** | затирание: вода + зерно/фрукты/мёд + GTH → сусло | уже есть механика ферментации: `Phase3Events.FERMENT_DELAY_TICKS` — 15 мин, фрукты → сусло |
| **Бродильный бак** | сусло → брага (время, тепло) | таймеры брожения **не кор-механика** (твоё решение уже записано) |
| **Дистиллятор** | брага → спирт-сырец (~40 %) | первый продукт |
| **Ректификатор** (отдельным блоком, как ты сказал) | спирт-сырец → **ректификат** (~96 %) | ключ к препаратам |

Побочные полезности: **спирт как топливо** (GTH в топки), ректификат → **ЭДТА** (через формальдегид),
водка как напиток. Ректификатор логично строить как «колонну» (несколько блоков в высоту — дешёвый
символ ректификации без нового мультиблока: чем выше, тем чище).

**Вопрос (важный, требует твоего слова):** связывать ли **водку с психикой** (быстрый −стресс, но
+зависимость)? Намёк на механику у нас уже есть — шкала зависимости и кризис от неё. Если ты против —
оставляем водку чисто бытовой/химической.

### 2.7 Обдуватель и чистая комната

**Твоё условие принято:** чипы делаются только в чистой комнате — замкнутый контур + **двойной
буфер с обдувкой** («гермоввод» = буфер из двух гермодверь с очистителями, отдельного блока нет).

**Важно (автор 22.09):** чистая комната будет работать **через эффект**, подробное описание — за
автором. Поэтому таблица ниже — черновик на случай, если эффект не закроет случай «грязно»:
считать состояние по признакам не обязательно, если эффект сам его даёт.

Состояние «чисто» предлагаю считать раз в ~5 с по четырём признакам:

1. **Контур закрыт** — тем же алгоритмом, что для радиации (переиспользуем: полость + замкнутость).
2. **Обдуватель работает** — GTU, избыточное давление (частицы/звук у выхода).
3. **Фильтр не забит** — общий расходник; засорение видно на HUD.
4. **Внутри нет «пылящих» блоков** — дробилка, измельчитель, известь, кориум, открытый огонь.

Плюс **правило тамбура**: комната «грязная» на N секунд, если обе двери буфера открывались
одновременно (или дверь держали открытой). Классика: заходишь — ждёшь, пока обдув выровняет.

Использование чипа (ответ автора 22.09): грязь даёт **больше брака** — станок работает, но выход
годных падает; материалы тратятся. То есть чистая комната — это не «выключатель», а множитель к
доле годных (и это лучше ложится на механику «совмещение × выход годных»).

Бонус-функция обдувателя: **разгоняет газовые облака** в радиусе (токсичность/Некроз — уже есть
механика, будет чем её «смывать»).

### 2.8 Щипцы и ковш (инструменты безопасности)

**Механика по словам автора (22.09), целиком:** «зашёл в свой свинцовый бункер, ПКМ по свинцовому
ящику — зашёл в свой сундук этот свинцовый; перетащил щипцы на свои урановые слитки или слитки на
щипцы — неважно; щипцы меняются на „Содержит 64 урановых слитка“; щипцы показывают уменьшенную
дозу, 64 слитка фонят как 19. Ты несёшь эти щипцы в инвентаре/руке к станку, кладёшь щипцы в станок —
мгновенно в том слоте, куда ты положил щипцы, появляются просто твои 64 слитка, а сами щипцы
выпадают на землю возле станка».

Технически это «предмет-контейнер с эффектом»: (1) NBT содержимого, (2) множители −90 % токсичность
и −60 % радиоактивность (числа из спеки) для носителя, (3) перехват вставки в слот сырья — станок
забирает содержимое, а предмет щипцов уходит в дроп рядом с блоком (как ведро, но не в слот выхода).

**Арифметика требует уточнения:** 19 / 64 = **0.297**, то есть −70 %, а не −60 % (по −60 % было бы
64 × 0.4 = 25.6 ≈ 26). Что берём за истину — «−60 %» в тултипе или «19 из 64» в примере?

Старое описание (до уточнения) — ниже, оно не противоречит, но было неточным:

* **Щипцы**: предмет-контейнер; перетаскиванием на предмет в инвентаре берут до **64 одного вида**;
  инструмент-тултип: имя «Щипцы», лор «содержит урановый слиток 53» (по правилу единиц — счёт
  предметов своим цветом, как «16 items/т»); содержимое: **−90 % токсичность, −70 % радиоактивность**
  (автор: «64 слитка фонят как 19»). Ключевое разделение: **щипцы снижают ИЗЛУЧАЕМОЕ предметом,
  хазмат — ПОЛУЧАЕМОЕ игроком**; вместе ≈ **−88 %**. Ковш — то же для жидкостей (mB) и для ртути/цезия
  (предметы), причём щипцы ртуть и цезий не берут ни в каком виде, кроме руды, поллуцита и киновари.
* Любой станок принимает щипцы **в слот сырья** и, если внутри есть нужный предмет, **забирает его
  из щипцов** и работает.
* **Ковш** — то же для жидкостей/раскалённого (порция, например 1000 mB), те же бонусы защиты.

**Что нужно уточнить (не додумываю):**

1. Фраза «а щипцы выбрасывают item-drop» — что именно они выбрасывают: остаток, если станок взял
   не всё? Или содержимое, если станок не принял? Или выброс при поломке щипцов?
2. Управление: «перетаскивая в инвентаре» — то есть **drag-and-drop** щипцов на слот (ванильное
   перетаскивание, у нас уже есть свой `CraftingMenuMixin`), или **ПКМ** по предмету? Drag честно
   реализуем, но о нём надо сказать игроку в заметках/подсказке.
3. Ковш: только жидкости или ещё и раскалённые предметы (чего нельзя взять щипцами)? И работают ли
   те же −90 / −60 %.
4. Износ: щипцы/ковш ломаются? (Предлагаю: да, но редко — иначе это вечная защита от всего.)

### 2.11 Литография (структура и 3 микросхемы)

**Уточнение автора 22.09:** «База это определённый узел 3×3 выложенный из **новых типов блоков**;
кстати Я передумал, станок под процессор это будет **многоблочная структура, которая определяется
через CTM, структура 3×3×2**». То есть вместо станка на площадке 3×3 — **собранный многоблок 3×3×2**,
и у нас под это уже есть образец в коде: `machines/steamgen/SteamGenStructure` (событийный валидатор
+ индекс «часть → контроллер» + `FORMED`) и Smart CTM-модель (`formed=true` → `_ctm`). Детект
структуры — код, CTM — внешний вид собранной машины; это два разных механизма, и оба у нас есть.

Прежняя схема (станок в центре площадки 3×3) — для истории:

```
вид сбоку          вид сверху
[0][станок][0]     [база][база][база]
[база][база][база] [база][станок][база]
                   [база][база][база]
```

То есть **станок стоит в центре площадки 3×3 из «баз»**, а тип микросхемы определяет **рисунок
кольца** (8 клеток вокруг станка). Проверка структуры — чтение 8 блоков по таймеру (дёшево, кэш).

**Предложение по «базам» (3–4 варианта) — чтобы рисунок читался глазом и был осмысленным:**

| вариант базы | из чего | смысл |
|---|---|---|
| **подложка** | кремний (очищенный) | основа |
| **p-база** | подложка + бор | бор уже есть, «p-тип» |
| **n-база** | подложка + фосфор/мышьяк | легирование n-типа (фосфор — новая позиция, дешёвая) |
| **металлизированная** | подложка + золото/серебро/медь | дорожки и контакты |

И тогда **3 микросхемы** (все — «микросхемы/чипы», не процессоры, как ты и сказал):

| микросхема | рисунок (пример) | куда идёт |
|---|---|---|
| **логическая** | 8 подложек | управление: редстоун-логика, автоматика машин, счётчики |
| **аналоговая / сенсорная** | 4 подложки + 4 металлизированных (крест) | приборы: нейтронный монитор, датчики, компараторы |
| **силовая** | 4 подложки + 4 p/n в шахматку | энергетика: инверторы, конденсаторы, приводы |

**Порядок производства предлагаю двухступенчатым (иначе «станок = чип из воздуха»):**

1. **Цех подготовки пластины** — и вот тут наконец пригодится лежащая без дела текстура
   `block/third/silicon_factory.png`: кремний + химия (резист/травитель с химзавода) + GTU/GTH →
   **готовая пластина**.
2. **Станок литографии** — пластина + рисунок базы + чистая комната + GTU → чип.

Неизвестный/неполный рисунок = **брак** с внятным сообщением (и, по-хорошему, подсказкой в заметках:
какой рисунок какой чип даёт — иначе игрок не догадается).

**Вопрос:** «база» — это **новый выделенный блок** (несколько вариантов) или набор *существующих*
блоков (кремниевый блок, золотой блок…)? От этого зависит, сколько новых блоков и текстур (плейсхолдеры).

| **0.1** | **Контур 2.0** (слои, толщина, двери, проходы/гермоввод, показ утечки) | от него зависят чистая комната, ящики, реакторы — это фундамент всей Эпохи III |
| **0.2** | **Инструменты безопасности**: щипцы, ковш, свинцовый/вольфрамовый ящик, тяжёлая дверь | без них нельзя безопасно работать с кеком и изотопами |
| **0.3** | **Химический завод** («ЭДТА/препараты/жёлтый кек/химия литографии») + абразив, фильтр, ампула | он кормит всё остальное |
| **0.4** | **Наполнитель** (ампулы, смешение, жидкие металлы) | нужен для препаратов и для жидких металлов реакторов |
| **0.5** | **ПЦФОЗ** (кек → фторид → изотопы; каскад) | ворота в реакторы; щипцы/ящики к этому моменту уже есть |
| **0.6** | **Сусловарение** (чан → бак → дистиллятор → ректификатор) | боковая ветка, но она даёт ректификат для ЭДТА |
| **0.7** | **Препараты** (Цистамин/Пентацин/ДТПА) | когда есть завод + ректификат + наполнитель |
| **0.8** | **Закатной станок** (ампулы, канистры, капсулы ТВЭЛов) | капсулы понадобятся уже на реакторах |
| **0.9** | **Чистая комната**: обдуватель, буфер, правило чистоты | перед литографией |
| **0.10** | **Литография**: цех пластин + станок + 3 микросхемы | финал базы, «управление» для всего дальше |
| **дальше** | Реакторы (7 семейств), чипы как обязательный ресурс, остальная Эпоха III | после базы, как ты и сказал |

Оценка честно: **это самая большая волна в моде** (9 машин + 4 инструмента/контейнера + 2 правила
мира: контур и чистота). Если хочется быстрее увидеть результат — предлагаю резать в таком порядке:
**сусловарение и препараты** отложить (они боковые), а 0.1–0.5 + 0.9–0.10 вести подряд.
