# Панельное GUI и динамические слоты реактора — 0.3.236

**Дата:** 17.10.2026 · **Базовая версия:** 0.3.235 · **Область:** экран панели, инвентарь и PNG placeholders.

## Что реализовано

- Обычный ПКМ открывает меню на сформированной панели реактора. Для несформированной панели и по Shift+ПКМ остаётся текстовая диагностика структуры.
- Меню хранит содержимое в BlockEntity панели, поддерживает сохранение/загрузку через NBT и принимает `uf_tvel` по одному предмету в активном слоте. Слоты доступны через GUI; sided automation не получает доступных слотов. И формула числа слотов, и фильтр `uf_tvel` — текущие рабочие допущения, не подтверждённые автором. При разрушении самой панели оставшиеся предметы выпадают в мир.
- Контейнер имеет вместимость до 18 мест. Число активных мест пересчитывается валидатором по числу чехлов. **Текущая рабочая реализация:** `S(0)=0`, `S(N)=min(18,N+2)` при `N>0`; первый чехол открывает три места, каждый следующий — ещё одно, cap достигается при 16 чехлах.
- Это арифметика из концепт-кандидата, а не подтверждённое автором правило. Хранение централизовано в панели; физическая связь слота с координатой отдельного чехла, burnup и топливный runtime не реализованы.
- Открытие меню проверяет сформированность и актуальное число слотов; после потери формы меню становится недействительным. Проверка не запускает формирование: действует существующий lifecycle-контракт панели.

## Порядок слоёв

1. **Z0** — `*_gui_bg*.png`, фон.
2. **Z1** — заливки полос/индикаторов.
3. **Z2** — `*_gui*.png`, передний лист GUI.
4. **Z3** — 18×18 рамки дополнительных активных слотов начиная с четвёртого.
5. **Z4–Z6** — vanilla slot tints/highlights, items и tooltips; их отрисовка не менялась.

Первые три машинных места являются частью основного GUI-листа. Дополнительные позиции размещаются по столбцам: три ряда в первой колонке, далее сверху вниз в каждой следующей. Холст 512×512 рисуется со смещением −128 относительно окна 176×166, поэтому машинные слоты на холсте `x=190…280`, `y=145…181` соответствуют локальным координатам экрана `x=62…152`, `y=17…53`. Инвентарь игрока и хотбар остаются в базовом меню без перестановок.
