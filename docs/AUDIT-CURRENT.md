**0.3.43:** UV-развёртки formed-блока переведены на кадр 96×96 (было 96×80):
формат .mcmeta-анимации требует квадратных кадров размером с ширину полосы
(как third_distiller 16×64 + mcmeta frametime/interpolate). Раскладка автора
96×80 не тронута внутри кадра, нижние 16px — запас; UV всех 54 срез-моделей
пересчитаны от высоты 96 (v = px/6). Анимация = нарисовать N кадров 96×96
стопкой вниз в том же PNG + добавить PNG.mcmeta ({"animation":{"frametime":N}});
без mcmeta одиночный кадр 96×96 — обычная статика. mcmeta пока нет.

**0.3.42:** начинка литографии по ТЗ автора (28.09.2026). Конвейер (y181):
вход 172 — только «суп-набор» (класть/брать), транзит 208/244 — ни класть ни
брать (и через Shift), выход 280 — только брать; шлак-слоты (y145) 190/226/262 —

320 тиков → «Вулканизация» 90 тиков (каждые 9 тиков скачок 28 GTU) → чип
варианта. Брак — на каждом из 3 шагов, шанс от чистоты воздуха: 100%→1%,
50%→9%, 10%→24%, 0%→36% (линейно между точками), вне контура («обычный»)→26%;
при браке заготовка пропадает, в шлак-слот шага падает 1× flint. Энергия:
хранение 29086 GTU, приём 322 GTU/сек (16100 милли/тик), течение 3.8 GTU/t,

**0.3.41:** литографическая фабрика — многоблок. Структура 3×3(XZ)×2(Y) по
авторским матрицам (вариант 1/2/3 = chip_1/2/3): D = алюминиевый блок /
нержавеющий блок / алюминиевый корпус, R = фарфор, C = резиновый блок,
B = боросиликатное стекло, S = фабрика (верхний центр, контроллер). При сборке 17
участников заменяются оболочкой-срезом UV-развёртки 96×80 (дно 48×48, бока 48×32,
верх 48×48; срез-модели 18×3, UV-математика в генераторе); оригиналы хранятся в BE
контроллера и возвращаются при распаде, сломанная оболочка выпадает оригиналом через
его loot. Формирование: постановка любого участника (EntityPlaceEvent + onPlace
фабрики), подавление повторной сборки при перестановке; после загрузки мира BE тиком
проверяет NBT-структуру по миру. ПКМ по любой части открывает GUI (раскладка из PNG
автора: 3 входа + 4 выхода + шкала (8,17) 16×52); у каждого варианта СВОЯ пара
silicon_factory_chip_N_gui*.png с фолбэком на общие silicon_factory_gui*.png.
Процесс-ЗАГЛУШКА до ТЗ автора: 1 суп-набор → 1 чип варианта за 100 тиков, без
энергии. Чистая комната: резиновый/нержавеющий/алюминиевый блоки добавлены в
clean_room_interior (корпус и трубы уже были: PipeCarrier покрывает все трубы).

конфигурации. Код мода не тронут.

**0.3.37:** только тулинг разработчика, код мода не тронут: убран `org.gradle.daemon=false`
(каждый запуск runClient стартовал с холодной JVM — отсюда ~7 минут), включены
`org.gradle.caching` и `org.gradle.configuration-cache` (ModDevGradle 2 поддерживает;
артефакты NFRT и так кэшируются в `~/.neoformruntime`). Первый запуск после правки
будет медленным, последующие — после compileJava почти сразу. Если configuration-cache
вдруг conflict с какой-то задачей — строку можно удалить без последствий.
