# Доска резонанса — Фаза 1 (рабочий блок, без сид-лока)

Распаковать поверх `D:\FAZO\gonzo tech mod\` (новая версия репо с
silk-touch/эффектами/кальцитом — эта, что вы прислали).

Новое:
- `com/gonzotech/chalkboard/` — весь портированный движок (core/ — 7D
  анализ размерностей, client/ — экран) + `ChalkboardBlock.java` +
  `ChalkboardClientHandler.java` (открытие экрана изолировано от общего
  кода — см. javadoc в файле).
- Правки в `ModBlocks.java`/`ModItems.java`/`ModCreativeTabs.java` —
  регистрация блока/предмета, добавлен во вкладку.
- Ассеты доски: blockstate/model×2/item-model/loot-table/lang×2 + **черновая
  текстура-плейсхолдер** (простой мел на зелёном с рамкой — не финальный
  арт, меняется в любой момент без правок кода).
- `info/gonzo_tech_chalkboard_design.md` — вся зафиксированная архитектура
  (16 задач, сид, per-player прогресс, сервер-валидация, предметы-открытия)
  — Фазы 2-4 ещё впереди.

Что это даёт прямо сейчас: ставите блок «Доска резонанса» из вкладки
креатива, ПКМ — открывается экран конструктора формул (случайная решаемая
загадка, 3 уровня сложности внутри самого экрана, sandbox-режим). Ничего
не блокирует крафты, прогресс не сохраняется — это тестовый прогон, чтобы
убедиться, что порт живой, прежде чем наворачивать сид-лок/сеть/прогресс
поверх.

После распаковки — `gradle build`.
